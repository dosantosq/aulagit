Git: comandos principais

Guia rápido com os comandos mais usados para iniciar, controlar e sincronizar projetos com Git e GitHub.

Configuração

Inicialização e configuração

  • git init cria um repositório Git vazio.
  • git clone <url> baixa um repositório para o computador.
  • git config --global user.name "Seu Nome" define o nome do autor.
  • git config --global user.email "seu@email.com" define o e-mail do autor.
Status

Verificando alterações

  • git status mostra o estado do repositório.
  • git log exibe o histórico de commits.
  • git diff mostra diferenças entre arquivos modificados.
  • git diff --staged mostra alterações já adicionadas à área de staged.
Adicionar

Preparando alterações

  • git add nome-do-arquivo adiciona um arquivo específico.
  • git add . adiciona todos os arquivos alterados.
  • git add -A adiciona todas as mudanças, inclusive exclusões.
  • git commit -m "Mensagem" salva as alterações com uma mensagem.
Branch

Branches e ramificações

  • git branch lista as branches.
  • git checkout -b nova-branch cria e entra em uma nova branch.
  • git checkout nome-da-branch troca de branch.
  • git merge nome-da-branch junta uma branch na branch atual.
Remoto

Trabalhando com repositórios remotos

  • git remote -v lista os remotes configurados.
  • git remote add origin <url> conecta um repositório remoto.
  • git push -u origin main envia alterações para o GitHub.
  • git pull origin main atualiza a branch local com alterações do remoto.
Desfazer

Desfazendo mudanças

  • git restore nome-do-arquivo descarta alterações não confirmadas.
  • git restore --staged nome-do-arquivo remove do estágio.
  • git reset --soft HEAD~1 desfaz o último commit mantendo mudanças.
  • git reset --hard HEAD~1 apaga o último commit e todas as mudanças.
Tags

Versões e marcações

  • git tag lista tags.
  • git tag v1.0.0 cria uma tag leve.
  • git tag -a v1.0.0 -m "Versão 1.0.0" cria uma tag anotada.
  • git push origin --tags envia tags para o remoto.
Arquivos

Arquivos e histórico

  • git ls-files mostra arquivos rastreados.
  • git rm nome-do-arquivo remove arquivo do repositório.
  • git mv antigo novo renomeia ou move um arquivo.
  • git stash guarda alterações temporariamente.
Exemplo prático

Fluxo básico de trabalho

git init git status git add . git commit -m "Primeiro commit" git branch -M main git remote add origin https://github.com/usuario/projeto.git git push -u origin main
Git é uma ferramenta essencial para versionamento de código e colaboração em equipe.
